# 高知旅行（ntvhm8）

2026年11月7日(土)〜10日(火)の高知3泊4日を、家族3人がスマホで見るためのアプリ。
資料（`work/旅行/国内/26高知/output/高知旅行_20260826.html`）を、旅行中にそのまま使える形に落としたもの。

作成: 2026-08-29

## 何のためのアプリか

**まだ計画段階なので、「計画を前に進めること」を第一にしている。**
いま何が決まっていて、何が残っていて、次に何をすればいいのかが、開いた瞬間に分かること。
旅行が近づいたら、そのまま当日の旅程表として使える。

## できること

| タブ | 中身 |
|---|---|
| **いま** | 出発までの日数、**決まった数／予約した数のリング**、「つぎにやること」1件、決まっていることの一覧、**4日間の食事の入り方の図** |
| **旅程** | 日を選ぶと、**その日の予定が何時に入っているかの帯**と、時刻順のリスト。旅行期間中は自動で今日が開く。食事には「軽」「本番」の印 |
| **決める** | 残り3つの決めごとを**タップで選べる**。選ぶとリングが進み、旅程や「決まっていること」にその場で反映される。**定休日のグリッド図**で順番の根拠を示す。予約7件のチェックリスト。決まった内容をDiscord用にコピーするボタンつき |
| **候補** | 14か所を行く日・行き方・営業時間・定休日つきで一覧（地図リンクつき）。Discordの17件を出した人ごとに絞れる。**見送った2件の理由を片道時間の図**で示す |

## 図でわかるようにしたところ

| 図 | 何が見えるか |
|---|---|
| **食事の入り方**（いま） | 4日分の食事を時刻の位置に丸で置いた。濃い丸＝腰を据えて食べる、薄い丸＝つまむ程度。**丸が近いところが詰まっている**のが一目で分かる |
| **その日の帯**（旅程） | 予定が朝・昼・夜のどこに寄っているか。移動／食事／見る／宿 を色分け |
| **定休日グリッド**（決める） | 5つの店・催し × 4日。酔鯨亭の月曜と安兵衛の日曜が赤く抜けるので、**11/7の夜にまとめるしかない**ことが見て分かる |
| **片道時間の軸**（候補） | 宿からの片道時間に各地を置き、60分に線を引いた。**見送った2件が線の外側にある**ことが理由そのものになっている |

## 気をつけている点

- **決めごとが旅程に反映される**。11/9の夜で「どんこ」を選ぶと、旅程の19:00がその場で「どんこ」に変わる
- **定休日を目立たせている**。酔鯨亭は月曜、屋台安兵衛は日曜、久礼の田中鮮魚店とどんこは水曜が休み。この噛み合わせで旅程の順番が決まっている
- **食事が重なっていることを隠していない**。4日で14回ぶんあるので、薄い丸は3人でシェアする前提
- **電波がなくても開く**。一度開いておけば、圏外でも見られる

## 使い方（スマホ）

1. 配布されたURLを Safari / Chrome で開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はアイコンから、アプリのように開ける

チェックの状態は**その端末の中だけ**に保存される。他の人の画面には反映されない。

## 直すとき

- 中身はすべて `index.html` の中にある。上のほうの `DAYS` `SPOTS` `REQS` `BOOKS` を書き換えれば画面が変わる
- **直したら `sw.js` の `ntvhm8-v1` の数字を1つ増やすこと**。増やさないと、古い画面が端末に残り続ける
- アイコンを作り直すときは `_icon.html` を編集して、headless Chrome のスクリーンショットで書き出す（512 / 192 / 180 の3サイズ）

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。これ1つで動く |
| `manifest.webmanifest` | ホーム画面に置いたときの名前・色・アイコンの指定 |
| `sw.js` | 圏外でも開けるようにする裏方 |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン |
| `_icon.html` | アイコンの元絵（作り直すとき用） |
| `.nojekyll` | GitHub Pages 用のおまじない |
